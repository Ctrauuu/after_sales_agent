# 09a · 项目初始化

> 这一步是搭地基。把 Hermes Agent 装好、配好 DeepSeek 大模型、启动 Gateway 验证飞书能通。做完这一步，你应该能在飞书上跟 Agent 说一句话并得到回复。

---

## 目标

*   安装 Hermes Agent 框架
    
*   配置 DeepSeek 大模型
    
*   启动 Gateway 并接入飞书（先接一个平台验证通路）
    
*   初始化项目目录结构
    

## 步骤

### 1. 克隆项目并安装 Hermes

```bash
# 安装 Hermes Agent（Linux/macOS/WSL）
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

# 重新加载 shell
source ~/.bashrc

# 验证安装
hermes --version
```

### 2. 初次配置

```bash
# 进入交互配置向导
hermes setup

# 选择 LLM Provider: deepseek
# 输入 API Key
# 选择模型: deepseek-v4
# 配置 Gateway: 选择 feishu
# 按提示输入飞书 App ID 和 App Secret
```

### 3. 创建项目目录结构

```bash
mkdir -p ~/suning-hermes-agent/{mcp-suning,skills,config,logs,mock-files}
cd ~/suning-hermes-agent

# 目录说明:
# mcp-suning/   → MCP Server 代码（对接苏宁数据库）
# skills/       → 自定义 Skill 文件（补充 Hermes 内置 Skill）
# config/       → 项目配置文件
# logs/         → 运行日志
# mock-files/   → 模拟数据文件
```

### 4. 配置环境变量

```bash
cp .env.example .env
vim .env
# 填入 DeepSeek API Key、MySQL 连接信息等
```

### 5. 启动 Gateway 验证

```bash
# 启动 Hermes Gateway（后台运行）
hermes gateway start

# 查看 Gateway 状态
hermes gateway status

# 查看日志确认飞书接入成功
tail -f ~/.hermes/logs/gateway.log
```

### 6. 飞书验证

*   在飞书中搜索你的机器人名称
    
*   发送"你好"
    
*   确认收到回复

## 避坑建议

*   飞书机器人需要在飞书开放后台配置"消息与群组"权限，否则收不到群聊 @消息
    
*   DeepSeek API 如果连接超时，检查是否需要配置代理 `LLM_BASE_URL`
    
*   Hermes Gateway 默认端口 8080，如果被占用，`hermes config set gateway_port 8081`
