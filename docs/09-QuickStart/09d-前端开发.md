# 09d · 前端开发——管理后台

> 这一步搭建 Vue 3 管理后台，让管理员能图形化管理用户权限、查看 MCP 服务状态、审计对话日志。

---

## 目标

*   初始化 Vue 3 项目
    
*   实现 5 个管理页面（用户权限、MCP服务、对话日志、Skill管理、系统监控）
    
*   联调后端 API
    

## 步骤

### 1. 创建项目

```bash
npm create vite@latest suning-admin -- --template vue
cd suning-admin
npm install
npm install element-plus @element-plus/icons-vue
npm install echarts vue-echarts
npm install axios dayjs
npm run dev
```

### 2. 配置 Element Plus + 路由

```javascript
// src/main.js
import { createApp } from 'vue'
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import * as ElementPlusIconsVue from '@element-plus/icons-vue'
import App from './App.vue'
import router from './router'

const app = createApp(App)
app.use(ElementPlus)
app.use(router)
for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, component)
}
app.mount('#app')
```
```javascript
// src/router/index.js
import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  { path: '/', redirect: '/dashboard' },
  { path: '/dashboard', component: () => import('../views/Dashboard.vue') },
  { path: '/users', component: () => import('../views/UserManagement.vue') },
  { path: '/mcp-services', component: () => import('../views/MCPServiceManagement.vue') },
  { path: '/conversation-logs', component: () => import('../views/ConversationLogs.vue') },
  { path: '/skills', component: () => import('../views/SkillManagement.vue') },
]

export default createRouter({ history: createWebHistory(), routes })
```

### 3. 封装 Axios 实例

```javascript
// src/api/index.js
import axios from 'axios'
import { ElMessage } from 'element-plus'

const api = axios.create({
  baseURL: 'http://localhost:8080/api/admin',
  timeout: 15000,
})

api.interceptors.response.use(
  (res) => res.data,
  (err) => {
    ElMessage.error(err.response?.data?.message || '请求失败')
    return Promise.reject(err)
  }
)

export default api
```

### 4. 按页面提示词开发

每个页面的完整提示词在 `07-前端页面提示词/` 目录下。按编号顺序开发：

*   07a → `src/views/UserManagement.vue`
    
*   07b → `src/views/MCPServiceManagement.vue`
    
*   07c → `src/views/ConversationLogs.vue`
    
*   07d → `src/views/SkillManagement.vue`
    
*   07e → `src/views/Dashboard.vue`
    

建议开发顺序：先 Dashboard（最直观）→ UserManagement → MCPService → ConversationLogs → SkillManagement。

## 避坑建议

*   Element Plus 图标需要用 `@element-plus/icons-vue` 单独引入
    
*   ECharts 在 Vue 3 中使用 vue-echarts 比直接操作 DOM 更方便
    
*   后端 API 还没开发完时，可以用 MSW（Mock Service Worker）或 Express 快速搭 Mock Server 给前端联调
