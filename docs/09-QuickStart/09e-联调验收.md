## 常见问题排查

| 问题 | 可能原因 | 解决 |
| --- | --- | --- |
| 飞书收不到消息 | 飞书开放后台未配置事件订阅 | 检查事件回调 URL 是否正确 |
| MCP 调用超时 | SQL 慢查询 | 检查数据表是否有索引，确认只读副本负载 |
| 图表中文乱码 | 服务器缺中文字体 | `apt install fonts-wqy-microhei` |
| 权限不生效 | 拦截器未正确注入 | 检查 Gateway 日志中的 UserContext |
| 记忆不召回 | FTS5 索引未更新 | `hermes memory rebuild-index` |
