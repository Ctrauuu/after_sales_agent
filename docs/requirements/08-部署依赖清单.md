# 08 · 部署依赖清单

> 这份清单列出项目运行所需的所有基础组件和依赖。按"先搭好基础设施，再装项目依赖"的顺序排，跟着走就行。

---

## 一、运行环境

| 组件 | 版本要求 | 说明 |
| --- | --- | --- |
| 操作系统 | Ubuntu 22.04+ / CentOS 8+ / Windows Server 2019+ | 推荐 Linux |
| Python | 3.12+ | Hermes Agent 运行环境 |
| Node.js | 18+ | 前端构建 + Hermes 部分 TS 模块 |
| Git | 2.40+ | 代码管理 |
| Docker | 24+ | Milvus、Redis 可选容器化部署 |

---

## 二、基础组件

| 组件 | 版本 | 用途 | 部署方式 |
| --- | --- | --- | --- |
| MySQL | 8.0 | 业务数据存储（只读连接） | 已有基础设施，配置只读账号和副本即可 |
| Milvus | Standalone 最新版 | 售后知识库向量存储 + 记忆向量检索 | Docker Compose 官方脚本部署 |
| Redis | 7.x | 会话上下文缓存、权限令牌缓存、Celery Broker | Docker 或 apt 安装 |

### Milvus Standalone 部署

```bash
# 下载官方部署脚本
curl -sfL https://raw.githubusercontent.com/milvus-io/milvus/master/scripts/standalone_embed.sh -o standalone_embed.sh
bash standalone_embed.sh start
```

### Redis 部署

```bash
# Docker 方式
docker run -d --name redis-suning -p 6379:6379 redis:7-alpine

# 或 apt 安装
sudo apt install redis-server -y
sudo systemctl enable --now redis-server
```

## 三、后端依赖

后端工程位于 `backend/`。推荐使用项目锁文件安装依赖：

```bash
cd backend
uv sync
```

### Python 包

以下依赖安装后即可运行 Hermes Agent + 项目扩展：

```bash
pip install hermes-agent          # Hermes Agent 核心框架

# MCP 服务
pip install mcp                   # MCP 协议 SDK
pip install fastmcp               # FastMCP 服务框架

# 数据库
pip install sqlalchemy==2.0.*     # ORM
pip install pymysql               # MySQL 驱动
pip install redis==5.*            # Redis 客户端

# 向量 & AI
pip install pymilvus              # Milvus Python SDK
pip install dashscope             # 百炼 Embedding SDK（如需）

# 图表生成
pip install matplotlib            # 图表渲染

# 异步任务
pip install celery[redis]         # Celery + Redis Broker

# HTTP 客户端（IM API调用）
pip install httpx                 # 异步 HTTP 客户端

# 工具
pip install pyyaml                # Skill 文件 YAML 序列化
pip install python-dotenv         # 环境变量管理
pip install numpy                 # 向量计算（语义路由、相似度）
pip install jsonschema            # MCP 参数 Schema Validation
pip install watchdog              # 配置文件热加载监视

# 可观测性
pip install opentelemetry-api opentelemetry-sdk opentelemetry-exporter-otlp-proto-http
```

### 环境变量配置（backend/.env）

```bash
# LLM 配置
LLM_PROVIDER=deepseek
LLM_API_KEY=sk-your-deepseek-api-key
LLM_MODEL=deepseek-v4
LLM_BASE_URL=https://api.deepseek.com/v1

# Embedding 配置
EMBEDDING_PROVIDER=dashscope
EMBEDDING_API_KEY=sk-your-dashscope-key
EMBEDDING_MODEL=text-embedding-v3

# MySQL 只读连接
MYSQL_HOST=10.0.1.100
MYSQL_PORT=3306
MYSQL_USER=suning_readonly
MYSQL_PASSWORD=your-readonly-password
MYSQL_DATABASE=suning_aftersale
MYSQL_REPLICA_SET=readonly_replicas

# Redis
REDIS_URL=redis://localhost:6379/0

# Milvus
MILVUS_HOST=localhost
MILVUS_PORT=19530

# Hermes 配置
HERMES_HOME=~/.hermes
HERMES_GATEWAY_PORT=8080

# 飞书
FEISHU_APP_ID=cli_xxx
FEISHU_APP_SECRET=xxx

# 企微
WECOM_BOT_ID=xxx
WECOM_SECRET=xxx

# 钉钉
DINGTALK_APP_KEY=xxx
DINGTALK_APP_SECRET=xxx
```

### Hermes 初始化

```bash
# 安装 Hermes Agent（如未安装）
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

# 配置大模型
hermes model
# 选择 deepseek:deepseek-v4

# 配置工具
hermes tools
# 启用: terminal, web_search, mcp_client, cron

# 配置 Gateway
hermes gateway setup
# 依次配置飞书、企微、钉钉
```

## 四、前端依赖

```bash
# 创建 Vue 3 项目
npm create vite@latest frontend -- --template vue

# 进入目录安装依赖
cd frontend
npm install

# 安装 UI 框架
npm install element-plus @element-plus/icons-vue

# 安装图表库
npm install echarts vue-echarts

# 安装工具库
npm install axios dayjs file-saver

# 启动开发服务器
npm run dev
```
