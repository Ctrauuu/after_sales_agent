# 07d · Skill管理

> 管理员在这里查看和管理 Agent 自动沉淀的技能。每个 Skill 是 Agent 从重复分析任务中自动学习出的一条可复用工作流——比如"退单原因分析"Skill 封装了从查退单→按品类聚合→按原因分类→生成结论的完整流程。

## 页面提示词

请用 Vue 3 + Vite + Element Plus 生成一个 Skill 管理页面，具体要求如下：

**页面目标**：管理员查看 Agent 自动创建的所有技能、手动启用/禁用、编辑触发模式、查看技能工作流详情。Skill 分为"自动创建"和"手动创建"两类，支持按类型筛选。

**页面布局**：上方筛选栏（技能类型、启用状态、搜索技能名），下方是 Skill 卡片网格（每行3~4张卡片）。每张卡片展示技能名称、描述、版本号、触发模式示例、使用次数、平均质量评分。点击卡片进入详情 Drawer。

**核心交互**：

1.  卡片网格：每张卡片包含技能名称（粗体）、一句话描述、版本号 Badge、触发模式预览（前2条）、使用次数和评分的统计条。右下角有启用/禁用开关。自动技能蓝色边框，手动技能灰色边框
    
2.  详情 Drawer：展示技能完整信息——描述、版本历史时间线、完整触发模式列表、工作流步骤可视化（步骤序号+工具名称+说明）、输出模板预览、使用统计（次数+质量评分趋势图）
    
3.  编辑触发模式：在 Drawer 中点击"编辑"，可修改触发模式（添加/删除触发语句）
    
4.  禁用技能：开关切换即可，无需二次确认；禁用后 Agent 不再自动匹配该技能
    
5.  删除技能：需二次确认，仅限手动创建的技能；自动技能不可删除（只能禁用）
    

**数据来源**：

*   GET /api/admin/skills?type=&status=&keyword=&page=&size= 获取技能列表
    
*   GET /api/admin/skills/:id 获取技能详情
    
*   PUT /api/admin/skills/:id 编辑技能（触发模式等）
    
*   PUT /api/admin/skills/:id/status 切换启用状态
    
*   DELETE /api/admin/skills/:id 删除技能
    

**UI 组件清单**：

*   el-card（技能卡片，可自定义 header）
    
*   el-badge（版本号角标）
    
*   el-tag（技能类型：auto蓝色/manual灰色）
    
*   el-switch（启用开关）
    
*   el-drawer（技能详情，size="50%"）
    
*   el-timeline（版本历史）
    
*   el-steps（工作流步骤可视化，方向垂直）
    
*   el-progress（质量评分进度条）
    
*   el-input / el-select（筛选栏）
    
*   el-message-box（删除确认）
    
*   el-empty（无技能时）
    

**边界情况**：

*   无技能时显示 Empty + 引导文字："尚无沉淀的技能。Agent 会在完成复杂分析任务后自动创建技能"
    
*   工作流步骤数 > 8 时，el-steps 切换为可折叠模式
    
*   质量评分趋势图使用 ECharts 折线图（CDN引入，挂载在 Drawer 内）
    
*   自动技能的"删除"按钮置灰并 tooltip："自动创建的技能不可删除，可选择禁用"
