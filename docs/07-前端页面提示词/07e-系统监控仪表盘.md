# 07e · 系统监控仪表盘

> 管理员在这里一览系统的整体运行状况——Agent 服务是否正常、MCP 连接是否健康、今日处理了多少条对话、用户活跃度如何。相当于系统的"驾驶舱"。

## 页面提示词

请用 Vue 3 + Vite + Element Plus 生成一个系统监控仪表盘，具体要求如下：

**页面目标**：为管理员提供系统运行状态的全景视图。展示核心指标卡片（今日对话数、活跃用户数、MCP调用总量、平均响应时间）、MCP 服务健康状态、最近告警事件列表。

**页面布局**：顶部一行4个指标统计卡片，中部左侧是"今日对话趋势"折线图（按小时），右侧是"MCP调用分布"饼图（按服务拆分），底部是"最近告警事件"表格。

**核心交互**：

1.  统计卡片：四个卡片分别展示"今日对话总数""活跃用户数""MCP调用总量""平均响应时间（秒）"。卡片含图标、数值、较昨日的环比变化（↑绿色/↓红色）。点击卡片跳转到对应的详情页（对话日志/MCP服务管理）
    
2.  今日对话趋势图：ECharts 折线图，X轴=小时（0-23点），Y轴=对话数量，支持 tooltip 悬浮看具体数值
    
3.  MCP调用分布图：ECharts 环形饼图，展示各 MCP 服务（订单/售后/商品/物流/支付）的调用量占比
    
4.  告警事件表格：列出最近20条告警事件——时间、级别（info/warning/error）、事件描述、状态（已解决/待处理）。error 级别行高亮红色背景
    
5.  页面顶部自动刷新：每30秒自动刷新一次数据，右上角显示"下次刷新倒计时"
    

**数据来源**：

*   GET /api/admin/dashboard/overview 获取四大指标卡片数据
    
*   GET /api/admin/dashboard/trend?date= 获取今日对话趋势
    
*   GET /api/admin/dashboard/mcp-distribution?date= 获取MCP调用分布
    
*   GET /api/admin/dashboard/alerts?limit=20 获取告警事件列表
    

**UI 组件清单**：

*   el-row + el-col（栅格布局，卡片区域 col-span=6，图表区域 col-span=12）
    
*   el-card（指标卡片，配合 el-statistic 或自定义内容）
    
*   el-tag（告警级别：info/warning/error；环比变化：success/danger）
    
*   el-table（告警事件列表）
    
*   el-pagination（告警事件分页）
    
*   ECharts（CDN引入，折线图 + 环形饼图，挂载在 el-card 内）
    
*   el-skeleton（加载骨架屏）
    
*   el-empty（无告警时）
    

**边界情况**：

*   首次加载时，统计卡片和图表区域显示 el-skeleton 骨架屏
    
*   无告警事件时，表格区域显示："暂无告警事件，系统运行正常"（绿色 Empty）
    
*   ECharts 容器 resize：窗口尺寸变化时图表自适应
    
*   环比数据为0时显示灰色"—"而非箭头
    
*   某 MCP 服务调用量为0时，饼图中不显示该扇区
    
*   自动刷新失败时，不弹错误提示，仅静默跳过本轮刷新，保留上次数据
