# 07c · 对话日志审计

> 管理员在这里查看所有用户的对话记录，用于问题排查、效果评估、安全审计。可以看到每条消息的提问内容、Agent 回复、调用了哪些 MCP 工具、耗时多少。

## 页面提示词

请用 Vue 3 + Vite + Element Plus 生成一个对话日志审计页面，具体要求如下：

**页面目标**：管理员查看和搜索所有用户与 Agent 的对话记录。支持按时间范围、用户、平台、话题类型筛选。每条日志可展开查看完整的多轮对话详情、MCP 调用链、耗时统计。

**页面布局**：顶部筛选栏（时间范围日期选择器、用户下拉、平台选择、话题类型、搜索关键词），下方是日志列表表格。点击某条日志，展开嵌套表格或 Drawer 显示该会话的完整多轮对话详情。

**核心交互**：

1.  筛选：日期范围选择器（默认近7天）、用户下拉（支持搜索）、平台多选（飞书/企微/钉钉）、话题类型下拉、关键词搜索框。筛选条件变更时自动重新加载
    
2.  日志列表表格：列包括会话ID、用户姓名、平台标签、首条提问（截断30字）、话题类型、轮次数、调用MCP次数、总耗时、时间。支持分页
    
3.  展开详情：点击某行的"查看详情"，Drawer 从右侧滑出，展示该会话的完整对话记录——每条消息显示发送者（用户/Agent）、消息内容（Agent 消息可能包含表格/图表链接）、该轮调用的 MCP 工具和耗时。底部汇总：总轮次、总调用次数、平均每条耗时
    
4.  导出：筛选后的日志支持导出为 CSV（前端实现，不依赖后端导出接口）
    

**数据来源**：

*   GET /api/admin/logs/conversations?start\_date=&end\_date=&user\_id=&platform=&topic=&keyword=&page=&size= 获取日志列表
    
*   GET /api/admin/logs/conversations/:session\_id/detail 获取某会话完整对话详情
    

**UI 组件清单**：

*   el-date-picker（时间范围选择，type="daterange"）
    
*   el-select（用户筛选、平台多选、话题类型）
    
*   el-input（关键词搜索，带 search 图标）
    
*   el-table（日志列表，列含 el-tag 平台标签、el-button 查看详情）
    
*   el-drawer（对话详情，size="60%"）
    
*   el-timeline（对话时间线展示，每条 el-timeline-item 含用户头像和消息气泡）
    
*   el-tag（平台标签、话题类型标签）
    
*   el-descriptions（详情汇总：总轮次、调用次数、平均耗时）
    
*   el-pagination
    
*   el-button（导出CSV）
    
*   el-empty（无日志时）
    

**边界情况**：

*   无日志记录时显示 Empty："所选条件下暂无对话记录"
    
*   某轮 Agent 回复包含图表，以"📊 \[查看图表\]" 文字链接展示
    
*   消息内容过长（>200字），默认折叠，点击"展开全文"
    
*   导出操作：数据量 > 5000 条时弹出提示"导出数据量较大，预计需要X秒，是否继续？"
    
*   网络加载中，表格区域显示 el-skeleton 骨架屏
