# 07a · 用户与权限管理

> 管理员在这里管理谁能用这个系统、能用什么功能。核心操作：添加/禁用用户、绑定IM平台账号、分配角色和权限范围。

## 页面提示词

请用 Vue 3 + Vite + Element Plus 生成一个用户权限管理页面，具体要求如下：

**页面目标**：管理员管理 Hermes Agent 的用户账号，包括添加用户、绑定飞书/企微/钉钉账号、分配角色（售后运营/区域经理/品控工程师/高层决策/客服主管）、配置每个用户的区域和品类权限范围。

**页面布局**：上下结构。上方是筛选栏（角色下拉框、状态筛选、搜索员工工号输入框、添加用户按钮），下方是用户列表表格。点击某行用户，右侧或底部展开抽屉显示该用户的详细信息（平台绑定列表、角色、权限范围）和操作按钮（编辑、禁用/启用、删除绑定）。

**核心交互**：

1.  添加用户：点击"添加用户"按钮弹出 Dialog 对话框，表单包含员工工号、姓名、角色选择、区域权限（多选：华东/华南/华北/西南）、品类权限（多选：大家电/3C/超市/美妆）、数据粒度（完整明细/脱敏明细/仅汇总）
    
2.  编辑用户：点击表格行操作列的"编辑"，弹出同上 Dialog 并回填数据
    
3.  绑定IM平台：在用户详情抽屉中，点击"绑定平台"，选择飞书/企微/钉钉，输入对应平台的用户ID，点击确认完成绑定。已绑定的平台显示绿色标签
    
4.  禁用/启用：开关切换，操作前二次确认弹窗
    
5.  表格支持分页、按角色筛选、按状态筛选（已启用/已禁用）
    

**数据来源**：

*   GET /api/admin/users?role=&status=&keyword=&page=&size= 获取用户列表
    
*   POST /api/admin/users 添加用户
    
*   PUT /api/admin/users/:id 编辑用户
    
*   PUT /api/admin/users/:id/status 切换启用状态
    
*   POST /api/admin/users/:id/bindings 绑定IM平台
    
*   DELETE /api/admin/users/:id/bindings/:platform 解绑平台
    
*   GET /api/admin/roles 获取可选角色列表
    

**UI 组件清单**：

*   el-table（用户列表，列：工号、姓名、角色、已绑平台标签、状态开关、创建时间、操作）
    
*   el-dialog（添加/编辑用户表单）
    
*   el-drawer（用户详情 + 平台绑定管理）
    
*   el-form + el-form-item（表单字段）
    
*   el-select（角色下拉、平台选择、数据粒度）
    
*   el-checkbox-group（区域权限多选、品类权限多选）
    
*   el-input（工号、姓名搜索）
    
*   el-tag（已绑定平台标签，feishu蓝色/wecom绿色/dingtalk橙色）
    
*   el-switch（启用/禁用开关）
    
*   el-pagination（分页）
    
*   el-message-box（删除确认）
    

**边界情况**：

*   用户列表为空时，显示 Empty 状态："暂无用户，点击上方按钮添加"
    
*   添加用户时工号重复，后端返回409，前端显示"该工号已存在"的错误提示
    
*   绑定平台时输入无效ID，后端返回400，显示具体错误信息
    
*   网络请求超时或失败，表格上方显示 Warning 条："加载失败，请点击重试"
    
*   表单提交中按钮 loading 状态防止重复提交
